# The Interface

A quick orientation to Pod's main window: the left rail, the status bar, and the
sync controls.

## The left rail

The left rail holds the character selector, the feature buttons, and the
Settings/About entries.

![Full left rail](/docs/img/interface/left-rail.png)

## The status bar

The bottom status bar shows server time, the sync chip, and ESI status.

![Bottom status bar](/docs/img/interface/status-bar.png)

## Sync controls

Click the sync chip to open the sync popover, with the job queue, last-synced
time, and a force-sync control.

![Sync popover](/docs/img/interface/sync-popover.png)

![Sync chip states](/docs/img/interface/sync-states.png)

## Updates

When a new release is available Pod surfaces an update banner.

![Update-available banner](/docs/img/interface/updater-banner.png)
