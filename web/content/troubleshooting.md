# Troubleshooting

Fixes for the most common snags. For installation and support questions, the
landing page [FAQ](/#faq) covers additional ground.

## macOS "damaged" warning

If macOS reports Pod is damaged, it has been quarantined by Gatekeeper — clear
the quarantine or allow the app in System Settings.

![macOS damaged dialog](/docs/img/troubleshooting/macos-damaged.png)

## Re-authorizing a character

When a token expires, re-authorize the affected character directly from its
card.

![Re-auth flow](/docs/img/troubleshooting/reauth-flow.png)

## Sync errors

A sync error shows on the sync chip and popover with a retry control.

![Sync error and retry](/docs/img/troubleshooting/sync-error.png)

## Database take-over

When sharing a networked database, Pod gates a take-over behind a data-loss
confirmation.

![Take-over confirmation](/docs/img/troubleshooting/take-over-confirm.png)
